# AulaNova IA

**Aprende. Crea. Resuelve.**

Aplicación Android educativa en español para estudiantes universitarios.

Incluye tutor académico local, laboratorios de matemáticas/estadística/contabilidad, conversores, fórmulas, fichas, quizzes, planificación, infografías, presentaciones, storyboards de video, melodías, voz y lectura en voz alta.

No requiere cuenta ni publicidad y guarda los datos localmente.

Nota: una IA generativa universal de calidad de frontera no puede garantizarse como “ilimitada y gratis” sin un servicio de cómputo. Esta edición prioriza herramientas locales gratuitas y no incluye API de pago.
